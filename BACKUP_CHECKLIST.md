# Backup Checklist

## Must back up
- Custom GPT name, instructions, starters, and knowledge files
- Project names, instructions, files, and notes
- Important chat transcripts
- Prompt templates
- Any exported files used in daily work
- GitHub repo links and access notes
- Notion pages, databases, and key URLs
- Google Sheets URLs and any formula notes
- Browser setup notes and bookmarks

## Likely to disappear or become inaccessible after Business cancellation
- Business workspace-only chats and projects
- Business workspace-only custom GPTs
- Files stored only inside Business projects
- Workspace-specific access to connected tools
- Workspace-specific settings and context

## Usually preserved outside OpenAI
- GitHub repositories
- Notion workspaces and pages
- Google Drive files
- Local files on disk
- Password manager entries

## Before canceling Business
- Confirm every critical item exists outside Business
- Recreate the important GPTs in Personal
- Reconnect GitHub and Google in Personal
- Run one real workflow test in Personal
- Keep Business active until the test passes
