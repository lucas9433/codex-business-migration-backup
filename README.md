# Codex Business Migration Backup

This repository is a migration backup for moving from ChatGPT Business + Codex to a Personal Pro/Codex setup.

## Files
- `MIGRATION_PROTOCOL.md` - step-by-step migration flow
- `BACKUP_CHECKLIST.md` - what to back up before canceling Business
- `WORKSPACE_INVENTORY.md` - inventory template for GPTs, projects, prompts, files, and integrations

## Rules
- Do not store passwords or raw OAuth tokens here.
- Keep secrets in your password manager or encrypted vault.
- Verify the Personal workspace before canceling Business.
